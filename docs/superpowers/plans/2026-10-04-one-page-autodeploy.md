# One-Page Auto-Deploy Workflow Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox syntax.

**Goal:** A GitHub Action that regenerates the one-page site from the live site's content and publishes it to `iamrbtm/iamrbtm.github.io` automatically on every push to `main`, every 6 hours (to pick up CMS database edits), and on demand.

**Architecture:** The workflow builds `one_page/index.html` on the runner with `scripts/build_one_page.py` (reads `https://jeremyguill.me/api/site-content.json` + the repo's reviewed copy files), validates it with `scripts/check_one_page.sh`, and copies only `index.html` into the Pages repo, committing only when the file changed. If production does not serve the JSON yet (HTTP 404), the run ends successfully with a notice and publishes nothing; every other failure fails the run and publishes nothing.

**Tech Stack:** GitHub Actions, astral-sh/setup-uv, Python 3.14 (project requires `>=3.14,<3.15`), existing generator and guard.

**Spec:** owner request 2026-10-04 ("auto generate the one page and deploy it to iamrbtm.github.io every time the repo is updated"); design approved ("go"): push to main + 6-hourly schedule + workflow_dispatch; generated page is built on the runner and NOT committed to this repo; quiet skip while production lacks the JSON feed.

- [ ] **Step 3: Write the workflow** to satisfy the tests. Shape:
  ```yaml
  name: Build and publish one-page site
  on:
    push:
      branches: [main]
    schedule:
      - cron: "23 */6 * * *"
    workflow_dispatch:
  permissions:
    contents: read
  concurrency:
    group: pages-publish
    cancel-in-progress: false
  jobs:
    publish:
      if: github.ref == 'refs/heads/main'
      runs-on: ubuntu-latest
      timeout-minutes: 10
      steps:
        - checkout this repo (persist-credentials: false)
        - uses: astral-sh/setup-uv@v<major>   (python 3.14 comes from `uv sync` honoring requires-python; if setup-uv needs `python-version: "3.14"` set it)
        - run: uv sync --frozen --no-dev
        - id: build
          name: Build one-page site
          run: |
            set +e
            uv run python scripts/build_one_page.py --output one_page/index.html
            code=$?
            set -e
            if [ "$code" -eq 3 ]; then
              echo "::notice::Production does not serve /api/site-content.json yet; skipping publish (deploy the main site first)."
              echo "skip=true" >> "$GITHUB_OUTPUT"
              exit 0
            fi
            exit "$code"
        - name: Check one-page build        (if: steps.build.outputs.skip != 'true')   run: sh scripts/check_one_page.sh
        - name: Checkout Pages repo         (same if) uses actions/checkout@v4 with repository iamrbtm/iamrbtm.github.io, token DEPLOY_TOKEN, path pages-repo
        - name: Copy index.html only        (same if) cp one_page/index.html pages-repo/index.html
        - name: Commit and push             (same if) working-directory pages-repo; no-op if `git status --porcelain` empty; identity github-actions[bot]; `git add index.html`; commit message "Publish one-page site from ${GITHUB_SHA::7}"; `git push`
  ```
  Note for scheduled runs `GITHUB_SHA` is the latest main commit, fine. Keep comments in the YAML short and explanatory. Also add `one_page/index.html` to `.gitignore` (generated on the runner; never committed).
